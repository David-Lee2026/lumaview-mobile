# LumaView Mobile

Local Android video player development based on mpv-android. Work is performed on an isolated implementation branch.

Target: ARM64 Android (minimum API 23), with Huawei Mate 20 X / HarmonyOS 4.0 as a target for later physical-device testing.

Requested features: visible playback controls, ROI zoom, ROI-adaptive GPU low-light enhancement, and visual clip export.

Current status: restoring the approved implementation work and provisioning the Android SDK/NDK. No mobile feature, device compatibility or APK verification is claimed by this initialization commit.

Build logs and artifacts are development evidence, not a physical-device certification. No private videos, account credentials or signing private keys belong in this repository.
