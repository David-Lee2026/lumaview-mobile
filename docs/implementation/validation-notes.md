## 自动化证据的含义

- `CoreTest` 检查黑边、选区映射、旋转、像素比例、区间与曝光参考数学；不能代替 GPU 像素或真实设备性能测试。
- `PlayerIntegrationTest.realTouchRenderingAndExports` 在 API 35 x86_64 模拟器中运行真实 libmpv APK，通过系统触控输入暂停、拖动进度、框选／应用 ROI、恢复全画面和拖动 A/B 手柄。原画／增强截图由原生实际渲染结果生成，并比较亮度。
- 同一集成测试对 UI 实际选定区间运行 FFmpeg JNI 原码流导出与 Media3 Transformer 精确导出，保留文件、计划和实际编码器摘要；还检查取消发生于 JNI 排队入口前时不会被重新激活。导出数据路径直接调用，不能声称完整 SAF 保存对话框已自动化覆盖。
- `verify_exports.py` 完整解码两个输出，比较复制模式视频／音频压缩包负载 SHA256、精确模式编码类型、尺寸和时长。包负载检查不能代替听音／音画同步验收。
- `verify_apk.py` 检查签名、应用包名、API、权限、唯一 ABI、ZIP 16 KB 对齐及每个 ELF LOAD 段至少 16 KB 对齐。静态对齐与真实 16 KB 页面设备运行是不同结论。
- CI 证据是否通过以具体 run 的结果和上传记录为准；失败 run 的 APK 不作为最终交付包。ARM64 job 不含运行设备。

## 当前实现边界

- APK 为调试签名测试包；runner 间证书可能变化，跨构建安装可能需要卸载旧包。尚未建立稳定发行签名。
- 原码流只接受可证实独立解码 IDR 的 H.264／HEVC。HEVC CRA 不当作 IDR；无法确认安全边界时拒绝并建议精确模式。起点回退至前一个 IDR，终点延展到下一个 IDR 或完整文件末尾。保存所选视频／音频／字幕轨道，容器不兼容时提示改用 MKV；确认窗列出省略的轨道。当前自动化素材为 H.264／AAC，HEVC 和字幕容器组合仍需专门验证。
- 精确模式强制重编码 H.264／AAC，禁止静默降低尺寸，使用微秒剪辑 API；最终边界仍受视频帧和音频编码帧粒度影响。只接受 SDR 单视频／单音轨源，可关闭音频，不保留字幕。多轨道源明确拒绝，提示先原码流导出所选轨道，再打开片段精确裁剪。
- 两种导出均保持媒体内容路径独立于播放增强、ROI 与用户临时旋转。没有将增强结果写入成片的模式。
- GPU 统计和显示共享渲染器实际选区；曝光历史在 GPU 内，锁定曝光跨场景切换保持，重选区或媒体／Surface 切换重置。原画、HDR、超过 2,073,600 源纹理像素时跳过增强链路并显示旁路。工作画面限制最长边 1920、总像素 2,073,600；4K 输入的增强前降采样优化仍未完成，因此 4K 保持原画。
- 私有 ABI 包含媒体／Surface／选区／请求编号和实际渲染回执；资源字节计数尚不可测，字段零是未提供数据，不能解释为内存实际使用零。完整颜色精度、噪声／细节数字验收、HDR 组合、长时热性能和全部设备负载降级仍未完成。
- 文件库包含递归目录、最近 20 条与播放位置。SAF 输入使用只读 FD，非定位提供方需明确同意后缓存；输出必须是系统新建的可确认空文档，拒绝源别名和无法确认安全性的目标。真实提供方撤权、磁盘不足和所有故障注入尚未覆盖。
- 单播放器入口、串行 native worker、Surface 终止释放和取消保护已实现；完整后台／前台、鼠标、蓝牙媒体键、无障碍与生命周期压力测试仍需执行。没有后台音频服务。
