# LumaView Mobile 0.1.1-test 使用说明

安装 ARM64 包 `LumaView-Mobile-0.1.1-test-arm64-v8a.apk`。这是调试签名测试包；如果系统提示与旧包签名冲突，卸载旧测试包后安装。卸载会清除应用自己的历史和授权记录，不会删除原始视频。

## 播放与进度

从文件页选择本地视频或授权目录。默认“兼容播放（软件解码）”；画面顶部“解码设置”可选择“硬件加速（复制解码）”，该选择会记忆。若硬件模式表现异常，切回兼容播放。

底部显示暂停／播放、快退 10 秒、快进 30 秒、进度、音量与 0.25–2× 倍速。拖动进度时暂时暂停并预览，松开后恢复拖动前的播放状态。进度以有效位置样本平滑更新，缺失样本不会归零；主动定位和暂停逐帧后退仍会移动到实际时间。

## 画面增强

点击“画面增强”选择自动均衡、弱光、极弱光或流畅优先。曝光偏移、暗部、对比度和饱和度可在暂停时调整并直接查看当前帧变化。“原画对比”保留当前选区和放大倍数；“锁定当前曝光”固定曝光，重新选区后解除。

增强修改视频像素，不改变手机屏幕背光。一般路径提供空间降噪与细节；shader 失败时自动切到兼容增强，并显示“降噪／细节已停用”；继续失败则恢复原画并明确显示增强停用。HDR 和源纹理超过 2,073,600 像素时保持原画，当前不支持 4K 增强。

## 区域放大与片段

“区域放大”进入框选，在视频内拖动手指或鼠标画框，调整边界后点“应用”。增强统计跟随可见区域；“全画面”恢复。选区不应画在黑边上。

“片段剪辑”显示 A/B 时间轴，拖动两个手柄确定区间。原码流模式会向外延展到可独立解码的边界；确认前查看实际区间。精确模式重编码 H.264/AAC，仅接受 SDR 单视频／单音轨源。保存通过系统新建文档选择位置；原视频不被覆盖。两种导出都不写入播放增强、ROI 或临时旋转。

## 查看诊断

“更多 → 诊断信息 → 复制诊断”包含版本、API、ABI、GPU/解码状态、渲染路径、回执与近期内核错误。出现黑屏时，这份文本可用于区分解码、显示和增强失败；无需上传个人视频。

本版的自动化验证使用 API 29 与 35 的 x86_64 模拟器和 ARM64 静态构建检查。华为 Mate 20 X／HarmonyOS 4.0 真机安装、实际素材及长时性能没有执行。完整边界见 [验证说明](validation-notes.md)。
