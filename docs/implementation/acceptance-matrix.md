C03：ELF／APK静态检查与4KB／16KB环境运行各列子记录。P03：速度音量属性与物理听音分开。E08：float与规范编码分别列结果。F01：原画、自动、ROI模式各20分钟并列实际档位；E10没有授权真实素材时BLOCKED。多环境汇总不得拿一个环境的PASS覆盖另一个的FAIL。
